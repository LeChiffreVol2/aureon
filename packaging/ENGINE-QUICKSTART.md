# Engine quickstart

Use [START-HERE.md](START-HERE.md) for one self-directed install-to-result route:
verify the release, install the generation profile, obtain the pinned TerraMind
assets, prepare user-owned Sentinel-2 data, and run one explicit generation job.
The guide also provides an independent KAO-TerraMind B segmentation route. The source companion and installed CLI require no private
run scripts or benchmark directories.

For Python integration use [PUBLIC-API.md](PUBLIC-API.md). For input details use
[INPUTS.md](INPUTS.md); for upload/submit/status/verified download use
[ASYNC-SERVICE.md](ASYNC-SERVICE.md). See [MODEL-SUPPORT.md](MODEL-SUPPORT.md) for
scope and [SUPPORT.md](SUPPORT.md) for errors. All model execution requires the
explicit `--execute-model` / `execute_model=True` opt-in.
